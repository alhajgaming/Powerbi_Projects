# Powerbi_Projects

A collection of Power BI dashboards, reports, and data analytics projects created for learning, practice, and portfolio development.

This repository contains multiple projects organized into separate folders. Each project includes dashboards, datasets, visualizations, and insights based on different business and analytical scenarios.

---

Each project/report is stored in its own folder.
